# OPC创业服务平台

> AI驱动的创业服务平台，连接OPC创业者与本地资源

## 🌐 在线预览

**网站地址**: https://pp3n47legqqac.ok.kimi.link

## ✨ 功能特点

- 🏠 **首页展示** - 平台介绍、核心优势、功能模块、数据统计、最新动态
- 📋 **政策查询** - 智能筛选、热门推荐、政策详情
- 🏢 **园区查询** - 多维筛选、配套设施、优惠政策
- 🛠️ **服务资源** - 分类浏览、服务商对接
- 📈 **成功案例** - 时间轴展示、创业故事
- 📞 **联系我们** - 联系表单、联系方式

## 🎨 设计特点

- 现代科技风格，专业且清新
- 蓝色系主色调 (#0066CC) + 橙色强调 (#FF9900)
- 流畅的动画效果和交互体验
- 完全响应式设计，支持手机、平板、电脑

## 🛠️ 技术栈

- **框架**: React 18 + TypeScript
- **构建工具**: Vite 7
- **样式**: Tailwind CSS 3.4
- **UI组件**: shadcn/ui
- **路由**: React Router DOM
- **图标**: Lucide React

## 📁 项目结构

```
app/
├── src/
│   ├── components/     # UI组件
│   ├── sections/       # 页面区块
│   ├── pages/          # 页面组件
│   ├── hooks/          # 自定义Hooks
│   ├── data/           # 数据文件
│   ├── types/          # 类型定义
│   └── styles/         # 样式文件
├── public/             # 静态资源
└── dist/               # 构建输出
```

## 🚀 快速开始

```bash
# 进入项目目录
cd app

# 安装依赖
npm install

# 开发模式
npm run dev

# 构建项目
npm run build
```

## 📱 响应式设计

- **桌面端** (>1024px): 完整版布局
- **平板端** (768px-1024px): 双列布局
- **手机端** (<768px): 单列布局，汉堡菜单
